# 01. GitHub Agentic Workflows とは

## 一言でいうと

**自然言語（Markdown）で書いた指示を、AI エージェントが GitHub Actions 上で実行する仕組み**です。
従来の Actions は「決まった手順を決まった通りに」実行しますが、Agentic Workflows は AI が**文脈を理解し、判断し、意味のあるアクション**（Issue 作成、PR レビュー、コメント投稿など）を行います。

## 従来の GitHub Actions との違い

| 観点 | 従来の Actions（YAML） | Agentic Workflows（Markdown + AI） |
|------|----------------------|-----------------------------------|
| 記述 | `run:` でコマンドを逐次記述 | 自然言語で「やりたいこと」を記述 |
| 柔軟性 | 固定ロジック | AI が文脈に応じて判断 |
| 書く人 | 開発者 | 開発者 + 非エンジニアでも可 |
| 安全性 | 任意のコマンドを実行可能 | 既定は読み取り専用。書き込みは **safe-outputs** 経由のみ |
| 実行主体 | ランナー | ランナー上で動く AI コーディングエージェント |

## ライフサイクル（書く → コンパイル → 実行）

```
┌──────────────────┐   gh aw compile   ┌────────────────────────┐   GitHub Actions   ┌─────────────────┐
│ workflow.md       │ ───────────────▶ │ workflow.lock.yml       │ ─────────────────▶ │ AI エージェント   │
│ (フロントマター+本文) │                   │ (堅牢化された Actions YAML) │                    │ が指示を実行       │
└──────────────────┘                   └────────────────────────┘                    └─────────────────┘
        ↑                                          │
   人間が編集                              両方を git にコミット
```

1. **Write（書く）**: `.github/workflows/<名前>.md` に、フロントマター（YAML 設定）と本文（自然言語の指示）を書く
2. **Compile（コンパイルする）**: `gh aw compile` で Markdown を**堅牢化された** GitHub Actions ワークフロー `.lock.yml` に変換する。設定の検証・セキュリティ強化・最終 YAML 生成が行われる
3. **Lock file（ロックファイル）**: `<名前>.lock.yml` が生成される。これが Actions が実際に実行するファイル
4. **Execute（実行する）**: トリガー条件（手動ディスパッチ、push、Issue 作成など）で Actions が起動し、AI エージェントが文脈に応じてアクションを実行する

> 🔑 **コンパイルの本質**: 「人に優しい Markdown を書く → コンパイラが機械向けの YAML を生成する」というコードのコンパイルと同じ発想です。`.md` を直接 Actions が読むのではなく、必ず `.lock.yml` を経由します。

## 主要な構成要素

### フロントマター（frontmatter）
Markdown 冒頭の `---` で囲まれた YAML 設定。**いつ実行するか（トリガー）**、**何にアクセスできるか（権限）**、**どの AI を使うか（エンジン）**、**何ができるか（ツール）** を定義します。

### 本文（markdown body）
フロントマターの後ろに書く自然言語の指示。AI への依頼内容・手順・制約・出力フォーマットを記述します。

### エンジン（engine）
指示を解釈・実行する AI プロバイダ。**GitHub Copilot（既定）**、**Claude（Anthropic）**、**Codex（OpenAI）**、**Gemini（Google）** に対応します。本リポジトリは **GitHub Copilot エンジン**に統一し、Copilot で選べる中級モデル（`claude-sonnet-4.6` / `gpt-5.4` / `gpt-5.3-codex` / `claude-haiku-4.5`）を使います（→ [references/model-policy.md](references/model-policy.md)）。

### ツール（tools）と MCP
AI が使える機能。GitHub 操作・Web 検索・ブラウザ自動化（Playwright）などを **MCP（Model Context Protocol）** 経由で利用します。

### safe-outputs（安全な出力）
**既定では AI は読み取り専用**です。Issue 作成・コメント投稿・PR 作成といった書き込みは、検証済みの `safe-outputs` を通してのみ実行できます。AI に直接の書き込み権限を渡さないことで、安全性を担保します。

## 何ができるか（ユースケース例）

- **PR の自動レビュー**（本リポジトリの同梱例）
- **Issue のトリアージ・ラベル付け**
- **日次アクティビティレポートの自動生成**
- **README / ドキュメントの自動更新**（本リポジトリの同梱例）
- **依存関係・コードのメンテナンス提案**
